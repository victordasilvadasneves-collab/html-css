tabelas em telas pequenas

Em telas pequenas, as tabelas podem ser difíceis de ler. Para tornar as tabelas mais legíveis, podemos usar CSS para torná-las responsivas. Uma abordagem comum é usar a propriedade overflow-x para permitir que a tabela seja rolada horizontalmente em telas menores.
